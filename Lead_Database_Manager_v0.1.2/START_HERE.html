Открыть локальный DEMO

Локальный режим использует отдельные демонстрационные данные в браузере. Он не подключается к Cloudflare и не меняет настоящую базу.

Для подключения настоящей базы

  1. Опубликуйте содержимое архива через GitHub → Cloudflare Workers Builds.
  2. Создайте D1 и выполните миграции 0001 и 0002 через SQL Console.
  3. Подключите D1 binding с именем DB.
  4. Добавьте секрет ADMIN_TOKEN в Worker.
  5. Откройте опубликованный адрес и войдите с тем же ключом.

Подробные шаги находятся в docs/CLOUDFLARE_DEPLOYMENT.md.
