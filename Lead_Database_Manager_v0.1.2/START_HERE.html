Открыть интерфейс проекта
Важно: это локальный предпросмотр внешнего вида. Реальное подключение Cloudflare D1 и Telegram проверяется после публикации проекта через GitHub и Cloudflare Dashboard. Node.js, Python, Docker и Wrangler на ваш компьютер устанавливать не нужно.
  1. Распакуйте ZIP-архив в любую папку.
  2. Дважды нажмите START_HERE.html.
  3. Нажмите «Открыть интерфейс проекта».
