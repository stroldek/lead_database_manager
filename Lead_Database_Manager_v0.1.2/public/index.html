Зарегистрировать webhook

Worker проверит токен бота через getMe и зарегистрирует защищённый webhook в Telegram. Секреты должны быть заранее добавлены в Worker Secrets в Cloudflare.

Ключ не сохраняется в браузере и очищается после запроса.
i

Webhook получает сообщения, отправленные самому боту. Новый лид записывается в базу только после явного согласия через кнопку в Telegram. Команда /stop отзывает согласие.
