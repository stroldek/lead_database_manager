# Changelog

## 0.2.0 — 2026-11-12

### Added
- Рабочий REST API для лидов, разделов, массовых операций, dashboard и activity log.
- D1 migration `0002_core_management.sql`: segments, lead_segments, activity_logs, search_jobs, chat_queue, chat_history, индексы и notes.
- Серверная пагинация списка лидов на 25 / 50 / 100 строк.
- Поиск и комбинированная фильтрация.
- Авторизация административного API через Cloudflare Secret `ADMIN_TOKEN`.
- Интерфейс создания, редактирования, просмотра и удаления лидов.
- Интерфейс управления разделами и привязкой лида к нескольким разделам.
- Массовые действия над выбранными лидами.
- Журнал операций.
- Локальный интерактивный DEMO-режим с синтетическими данными.
- Инструкция по настройке D1 и Worker полностью через Dashboard.

### Preserved
- Защищённый Telegram webhook.
- Проверка согласия до добавления профиля Telegram.
- Отзыв согласия через `/stop`.
- Защита от повторной обработки Telegram update_id.

### Limitations
- Полноценные многопользовательские роли и аккаунты ещё не реализованы.
- Импорт / экспорт ещё не реализован.
- Массовые Telegram-коммуникации не реализуются.
- D1 binding и миграции требуют однократной настройки через Cloudflare Dashboard.
