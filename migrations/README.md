# Миграции

Порядок выполнения для чистой D1-базы:

1. `0001_stage1_prototype.sql` — базовые таблицы leads, consent_events, telegram_updates и индексы.
2. `0002_core_management.sql` — разделы, связь многие-ко-многим, аудит, будущие таблицы search_jobs / chat_queue / chat_history и индексы.

Обе миграции предназначены для Cloudflare D1 SQL Console и должны быть выполнены в указанном порядке. `0002` допускает повторное выполнение без создания дубликатов таблиц, индексов и стартовых разделов. После применения проверьте `schema_migrations`.

`../docs/FUTURE_SCHEMA.sql` — справочная схема проектирования. **Не запускать**: это не миграция и не часть текущей базы. Уже опубликованные migration-файлы не редактировать; новые изменения оформлять отдельными файлами `0003_...sql` и далее.
